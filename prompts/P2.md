# P2: Form a Valid Arithmetic Equation — Prompts

## Prompt 1 — Expression Tree Builder & Exact Evaluator (`expr_val/3`)
Using prolog-dev conventions (SWI-Prolog 9.x, only allowed libraries, no assert/retract, globals, or string-eval hacks), implement the first unit of code/61_q2.pl: a pure relational expression tree generator and exact-integer evaluator expr_val(Nums, Tree, Val) over operators +, -, *, / that preserves number order, allows negative intermediate values, and permits division only when the divisor is non-zero and divides evenly with zero remainder.
## Prompt 2 — Canonical Expression Formatter (`expr_to_string/2`)
Using prolog-dev conventions, add a canonical expression-to-string formatter expr_to_string(Tree, Str) to code/61_q2.pl that converts num(N) and bin(Op, L, R) into an SWI-Prolog string with no spaces, applying the exact precedence (*, / tighter than +, -) and left-associativity parenthesization rules (left child parenthesized only if strictly lower precedence; right child parenthesized if lower or equal precedence; single numbers never parenthesized).
## Prompt 3 — Single Equation Generator (`generate_equation/2`, P2.a)
Using prolog-dev conventions, add generate_equation(List, Equation) to code/61_q2.pl for P2.a so that it splits List into non-empty left and right parts, finds expression trees with equal exact integer values, and unifies Equation with the canonical SWI-Prolog string "L=R", failing cleanly (without looping or raising an error) when no valid equation exists or when List has length 0 or 1.
## Prompt 4 — All Equations & Counter (`all_equations/2`, `count_equations/2`, P2.b)
Using prolog-dev conventions, add all_equations(List, Equations) and count_equations(List, N) to code/61_q2.pl for P2.b so that all_equations/2 collects all valid canonical equation strings without duplicates sorted by sort/2 (returning [] if none exist, including for empty or single-element lists) and count_equations/2 unifies N with the length of that list.
## Prompt 5 — P2 Test Suite (`tests/test_p2.pl`)
Using prolog-dev conventions, write a standalone SWI-Prolog test file tests/test_p2.pl that loads ../code/61_q2.pl and tests generate_equation/2, all_equations/2, and count_equations/2 on all spec examples ([4,2,5,3], [2,3,4], [2,4,8]) plus edge cases (empty list, single element, zero division safety, exact-only division, negative intermediate values, and canonical parenthesization distinguishing 1+2+3 vs 1+(2+3) and SWI-Prolog string/1 type checks).
